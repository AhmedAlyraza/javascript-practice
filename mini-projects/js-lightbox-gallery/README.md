# JS Lightbox Gallery

A modern and advanced JavaScript lightbox gallery with navigation, zoom, and touch support.

## 🚀 Features

- Image popup preview
- Next / Previous navigation
- Keyboard controls (ESC, Arrow keys)
- Zoom functionality
- Swipe gestures (mobile support)
- Image preloading
- Accessible UI (ARIA support)

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript (Vanilla JS)
