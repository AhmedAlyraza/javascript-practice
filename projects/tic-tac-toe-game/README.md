# Tic Tac Toe Game (JavaScript)

A simple 2-player Tic Tac Toe game built using Vanilla JavaScript.

## 🎮 Features

- Two player mode (X vs O)
- Custom player names
- Win and draw detection
- Restart and new game options
- Interactive UI with popup messages

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Run

Open `index.html` in your browser.
