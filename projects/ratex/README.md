# RateX 💱

RateX is a modern currency converter web application built using JavaScript and a real-time exchange rate API.

## Features
- Real-time currency conversion
- Clean and modern UI (glassmorphism design)
- Currency swap functionality
- Country flag updates based on selection
- Error handling for invalid inputs

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- Exchange Rate API

## How to Use
1. Enter an amount
2. Select currencies
3. Click "Get Exchange Rate"
4. View converted result instantly

## Setup
- Clone the repository
- Open `index.html` in your browser

## Note
This project is built for learning and portfolio purposes and does not include backend or secure API handling.
