# Student Result Calculator (JavaScript)

A simple web app to calculate subject-wise results, percentages, and grades.

## 🎯 Features

- Add multiple subjects
- Automatic percentage calculation
- Grade system (A+, A, B, etc.)
- Grand total and overall grade
- Dynamic table updates

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Run

Open `index.html` in your browser.

## 📈 Future Improvements

- Edit/Delete rows
- Local storage support
- Export results (PDF/CSV)
