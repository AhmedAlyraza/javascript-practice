# Marks Analyzer (JavaScript)

A simple app to track student marks and calculate total and average.

## 🚀 Features

- Add marks dynamically
- Input validation (0–100 range)
- Display marks in table format
- Calculate total and average
- Clean and simple UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Use

Enter marks and click "Add", then click "Calculate" to get results.
