# Number Analyzer (JavaScript)

A simple JavaScript tool that analyzes a number and provides useful insights.

## 🚀 Features

- Detects even or odd numbers
- Identifies positive, negative, or zero
- Checks for prime or composite numbers
- Instant result display

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Use

Enter a number and click "Analyze" to see results.
