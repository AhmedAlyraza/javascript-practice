# Vowel Counter & Highlighter

A simple JavaScript app that counts vowels and highlights them in real-time.

## 🚀 Features

- Live text preview
- Vowel highlighting
- Dynamic vowel count table
- Clean and responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Use

Type text and click "Analyze" to see vowel counts.

## 📌 Future Improvements

- Support for consonants
- Textarea instead of input
- Copy/export results
