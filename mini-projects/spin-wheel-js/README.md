# Spin Wheel (JavaScript)

A fun interactive spin wheel game built using Chart.js.

## 🎯 Features

- Random spin logic
- Animated rotation effect
- Dynamic result display
- Chart.js based wheel rendering
- Clean UI with responsive design

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js

## ▶️ How to Use

Click the "Spin" button to rotate the wheel and get a random result.
