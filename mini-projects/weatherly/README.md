# Weatherly 🌤

A modern weather application built with JavaScript using the OpenWeatherMap API.

## Features
- Search weather by city
- Real-time temperature display
- Weather condition icons
- Humidity and wind speed
- Clean modern UI

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)
- OpenWeatherMap API
