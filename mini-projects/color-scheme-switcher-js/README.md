# Color Scheme Switcher (JavaScript)

A simple JavaScript app that allows users to switch between different background color themes.

## 🚀 Features

- Click-based color switching
- Dynamic background and text color updates
- Clean and minimal UI
- Interactive color preview buttons

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Use

Click on any color box to change the background theme.

## 📌 Future Improvements

- Add more color themes
- Save selected theme (localStorage)
- Add smooth transition animations
