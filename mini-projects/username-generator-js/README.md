# Username Generator (JavaScript)

A simple tool that generates usernames from a full name and allows quick copying.

## 🚀 Features

- Generate username from full name
- Auto lowercase and remove spaces
- Adds length-based uniqueness
- One-click copy to clipboard
- Modern UI design

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

## ▶️ How to Use

Enter your full name and click "Generate" to get a username.
